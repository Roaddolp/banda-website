# Exhibition photo assets

25 photographs, each with a desktop and smaller WebP variant: 50 WebPs totaling 4,993,340 bytes (4.76 MiB).

## Preparation and ordering

- Originals are preserved outside the website repository in the workspace `exhibit photos/` folder.
- JPEG orientation is applied before resizing. Embedded profiles are converted to sRGB; WebPs retain an sRGB profile and omit EXIF/XMP metadata.
- Desktop copies use a maximum 1920px edge at WebP quality 82; smaller copies use a maximum 1080px edge at quality 78. No cropping or upscaling.
- Three original CR2 files use their full-resolution embedded camera JPEG renders; no RAW sensor demosaicing is claimed.
- Photoshoot JPEGs were added separately without re-encoding the original 40 optimized WebPs.
- Manifest order is authoritative. The final Group Pic retains its original `20-group-pic-01` asset stem but appears at sequence 25.
- Chapter labels remain internal and are not displayed in the gallery.
